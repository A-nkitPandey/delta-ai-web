# Security policy

We take the security of deltaaiinnovation.in and our clients' data seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Instead, use one of these:

- GitHub: **Security → Report a vulnerability** on this repository (private advisory), or
- Email **info@deltaaiinnovation.in** with the subject `Security report`.

Include what you found, the steps to reproduce it and the impact you expect. We will acknowledge your report within **3 business days** and keep you updated until it is fixed.

## Scope

- The website and its API routes: `/api/contact`, `/api/chat`, `/api/extract`, `/api/whatsapp`
- This repository's code and GitHub Actions workflows

Out of scope: denial-of-service, spam, social engineering, and findings in third-party services (Cloudflare, Meta) that should go to those vendors.

## Please don't

- Access, change or delete data that isn't yours
- Run automated scanners that send large volumes of requests
- Publicly disclose an issue before we have fixed it

Thank you for helping keep our users safe.
